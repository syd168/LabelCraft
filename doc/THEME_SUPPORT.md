# LabelCraft 主题系统改进说明

## 概述
LabelCraft 现在具有完整的系统主题支持，可以自动跟随操作系统的亮色/深色模式偏好。

## 改动内容

### 1. 新增主题管理模块
**文件:** `libs/theme_manager.py`

提供两个主要函数：
- `apply_system_theme(app)` - 应用系统主题到应用程序
- `is_system_dark_mode()` - 检测当前是否为深色模式

### 2. 更新应用启动流程
**文件:** `labelcraft_ui.py`
**函数:** `get_main_app()`

- 导入新的主题管理模块
- 在应用启动时调用 `apply_system_theme(app)`
- 应用使用 Fusion 样式以获得更好的跨平台主题支持

### 3. 更新 CLI 入口点
**文件:** `libs/cli.py`

CLI 现在会自动应用系统主题，无论从哪里启动都能获得正确的主题。

## 工作原理

1. **Fusion 样式** - 使用 PySide6 的 Fusion 样式，它支持自动光亮/深色模式
2. **系统调色板** - 从系统获取当前的调色板（颜色主题）
3. **自动应用** - 在应用启动时自动应用系统调色板

## 兼容性

- ✅ Linux (GNOME, KDE, 等)
- ✅ macOS (Light/Dark mode)
- ✅ Windows 10/11
- ✅ Python 3.8+
- ✅ PySide6 6.5+

## 用户使用

无需用户操作，应用会自动：
1. 检测系统当前主题
2. 应用对应的浅色或深色模式
3. 在系统主题改变时跟随更新（需要重启应用）

## 技术细节

### 主题检测原理

```python
# 通过检查 Base 颜色的亮度值来判断
is_dark = base_color.value() < 128
```

- `value() < 128` - 深色模式
- `value() >= 128` - 亮色模式

### Fusion 样式优势

- 跨平台一致性
- 原生主题集成
- 性能优化
- 支持自定义调色板
