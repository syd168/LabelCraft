## 快速开始

### 启动应用

**Linux/macOS:**
```bash
./start.sh
```

**Windows:**
```bash
start.bat
```

**或直接运行:**
```bash
python main.py
```

> **提示**: LabelCraft 基于 labelImg 开发，保留了原有的命令行启动方式。

### 首次使用

1. **打开图片**: 点击 `文件 → 打开` 或按 `Ctrl+O`
2. **创建标注框**: 点击工具栏的 "创建矩形框" 按钮或按 `W` 键
3. **输入标签**: 在弹出的对话框中输入对象类别名称
4. **保存标注**: 点击 `文件 → 保存` 或按 `Ctrl+S`

### 右侧面板说明

#### 标注框列表
- 显示当前图片中所有已创建的标注框
- 每个标注框前有复选框，可以控制显示/隐藏
- 双击可编辑标签名称
- 右键可删除或编辑

#### 使用默认标签
- 勾选后，创建新标注框时不会弹出标签输入对话框
- 自动使用下拉框中选中的标签
- 适合批量标注同一类别的对象

#### 标注为困难样本
- 标记难以识别或不确定的对象
- 保存后会在 XML 文件中添加 `<difficult>1</difficult>`
- 训练时可以选择不使用这些样本

## 基本操作

### 1. 打开图片

**单张图片:**
- 菜单: `文件 → 打开`
- 快捷键: `Ctrl+O`
- 支持格式: JPG, PNG, BMP, TIFF 等

**整个文件夹:**
- 菜单: `文件 → 打开目录`
- 快捷键: `Ctrl+U`
- 会自动加载目录下所有图片

### 2. 创建标注框

**步骤:**
1. 确保处于 "创建模式" (工具栏第一个按钮高亮)
2. 在图片上按住鼠标左键拖动
3. 释放鼠标后输入标签名称
4. 按 Enter 确认

**技巧:**
- 按住 `Ctrl` 键可以绘制正方形
- 使用方向键微调标注框位置
- 滚轮可以缩放图片

### 3. 编辑标注框

**移动标注框:**
- 切换到 "编辑模式" (快捷键 `Ctrl+J`)
- 鼠标拖拽标注框到新位置

**调整大小:**
- 在编辑模式下，拖拽标注框的边缘或角点

**修改标签:**
- 在标注框列表中双击标签名称
- 或在画布上双击标注框

**删除标注框:**
- 选中后按 `Delete` 键
- 或在列表中右键选择删除

### 4. 保存标注

**保存格式:**
- PASCAL VOC (XML) - 默认格式
- YOLO (TXT) - 用于 YOLO 模型训练
- CreateML (JSON) - 用于 Apple CreateML

**切换格式:**
- 菜单: `文件 → 更改保存格式`
- 快捷键: `Ctrl+Y`

**自动保存:**
- 菜单: `视图 → 自动保存模式`
- 启用后，切换到下一张图片时自动保存

## 高级功能

### 1. 加载预定义标签

**为什么要用:**
- 避免每次手动输入标签
- 保证标签名称一致性
- 提高标注效率

**使用方法:**

**方法一: 启动时指定**
```bash
python main.py data/predefined_classes.txt
```

**方法二: 运行时加载**
- 菜单: `文件 → 加载标签文件`
- 快捷键: `Ctrl+Shift+L`
- 选择包含标签列表的文本文件

**文件格式:**
```txt
person
car
dog
cat
```
每行一个标签，支持中文和英文。

### 2. 复制前一帧标注

**适用场景:**
- 视频帧标注
- 连续图片中对象位置变化不大

**操作:**
- 菜单: `文件 → 复制前一帧标注框`
- 快捷键: `Ctrl+V`

### 3. 验证模式

**用途:**
- 检查已完成的标注
- 标记已验证的图片

**操作:**
- 按空格键切换验证状态
- 已验证的图片文件名前会显示 ✓

### 4. 亮度调节

**功能:**
- 调整图片显示亮度
- 不影响原始图片

**操作:**
- 工具栏亮度滑块
- 快捷键: `Ctrl+Shift++` (增亮), `Ctrl+Shift+-` (变暗)
- `Ctrl+Shift+=` 重置亮度

### 5. 颜色设置

**修改线条颜色:**
- 菜单: `编辑 → 改变线条颜色`
- 快捷键: `Ctrl+L`

**修改填充颜色:**
- 在标注框上右键
- 选择 "选择线条颜色" 或 "选择填充颜色"

## 常见问题

### Q1: 如何切换语言？

**A:** 菜单 `语言 → 选择语言`，支持:
- English
- 简体中文
- 繁體中文
- 日本語

### Q2: 标注文件保存在哪里？

**A:** 
- 默认保存在图片同目录
- 文件名与图片相同，扩展名为 `.xml` (VOC) 或 `.txt` (YOLO)
- 可通过 `文件 → 更改保存目录` 修改

### Q3: 如何批量标注同一类别？

**A:**
1. 勾选 "使用默认标签"
2. 在下拉框中选择类别
3. 直接绘制标注框，无需每次输入

### Q4: 标注框画错了怎么办？

**A:**
- 按 `Ctrl+Z` 撤销 (如果启用了)
- 或选中后按 `Delete` 删除
- 或在列表中右键删除

### Q5: 如何查看已标注的数量？

**A:**
- 窗口标题栏显示: `LabelCraft 图片.jpg (1/100)`
- 括号中分别是当前序号和总数
- 右侧列表显示所有标注框

### Q6: 支持什么标注格式？

**A:**
- **PASCAL VOC** (XML): 通用格式，大多数框架支持
- **YOLO** (TXT): YOLO 系列模型专用
- **CreateML** (JSON): Apple CreateML 框架

### Q7: 如何处理困难样本？

**A:**
1. 创建或选中标注框
2. 勾选右侧 "标注为困难样本"
3. 保存后 XML 中会有 `<difficult>1</difficult>`
4. 训练时可选择忽略这些样本

### Q8: 图片太大/太小怎么办？

**A:**
- 使用 `Ctrl++` / `Ctrl+-` 缩放
- 或 `Ctrl+F` 适应窗口
- 或使用鼠标滚轮缩放
- 按住 `Ctrl` + 滚轮更快缩放

### Q9: 如何备份标注数据？

**A:**
- 定期复制整个项目文件夹
- 或使用版本控制系统 (Git)
- 标注文件是文本格式，易于管理

### Q10: 程序崩溃了，标注会丢失吗？

**A:**
- 如果启用了 "自动保存模式"，不会丢失
- 建议开启自动保存: `视图 → 自动保存模式`
- 养成经常按 `Ctrl+S` 保存的习惯
