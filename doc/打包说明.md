## 📝 创建新版本发布的完整流程

### Step 1: 更新版本号

编辑 `libs/__init__.py`：
```python
__version_info__ = ('1', '8', '11')  # 修改版本号
__version__ = '.'.join(__version_info__)
```

### Step 2: 提交代码并创建标签

```bash
# 1. 添加所有修改的文件
git add -A

# 2. 提交代码（编写清晰的提交信息）
git commit -m "Release v1.8.11: Fix dark/light mode color adaptation

- Remove hardcoded colors from UI elements
- Use Qt palette system for theme-adaptive colors
- Fix text visibility in both light and dark modes"

# 3. 创建版本标签
git tag -a v1.8.11 -m "Version 1.8.11 - Dark/Light Mode Color Adaptation Fix"

# 4. 推送到 GitHub
git push origin main
git push origin v1.8.11
```

**标签命名规范**：
- 使用语义化版本：`v主版本.次版本.修订版本`
- 例如：`v1.8.11`、`v2.0.0`
- 标签消息应简要描述本次更新的主要内容

### Step 3: 等待 GitHub Actions 自动处理

访问：`https://github.com/syd168/LabelCraft/actions`

你会看到：
- ✅ CI Tests 运行中...（测试多平台兼容性）
- 🏗️ Build Releases 运行中...（构建各平台安装包）

### Step 4: 手动构建 PyPI 分发包

虽然 GitHub Actions 可以自动构建，但推荐使用本地构建以确保质量：

```bash
# 1. 清理旧的构建文件
rm -rf dist/ build/ *.egg-info

# 2. 构建 wheel 和 source distribution
python setup.py sdist bdist_wheel --universal

# 3. 检查生成的文件
ls -lh dist/
# 应该看到：
# - labelcraft-1.8.11-py2.py3-none-any.whl (wheel包)
# - labelcraft-1.8.11.tar.gz (源码包)
```

**验证构建产物**：
```bash
# 检查 wheel 包内容
unzip -l dist/labelcraft-1.8.11-py2.py3-none-any.whl

# 检查 tar.gz 包内容
tar -tzf dist/labelcraft-1.8.11.tar.gz | head -20
```

### Step 5: 上传到 PyPI

#### 方法一：使用 twine（推荐）

```bash
# 1. 确保已安装 twine
pip install twine

# 2. 上传到 PyPI（会提示输入用户名和密码）
twine upload dist/labelcraft-1.8.11*

# 或者使用 API token（更安全）
twine upload --username __token__ --password pypi-xxx dist/labelcraft-1.8.11*
```

#### 方法二：使用 setup.py（快速方式）

```bash
python setup.py upload
```

**注意**：首次上传需要：
1. 在 [PyPI](https://pypi.org/) 注册账号
2. 创建项目（首次上传时自动创建）
3. 配置 API token（推荐）或用户名密码
4. 并且将获得的token和账号信息存放到~/.pypirc 中，示例如下(username =\_\_token\_\_，password=获取的token):

   ```
   [pypi]
     username = __token__
     password = pypi-............................
   ```

### Step 6: 验证发布结果

#### 检查 PyPI 页面
访问：`https://pypi.org/project/LabelCraft/1.8.11/`

确认：
- ✅ 版本号正确
- ✅ 描述和 README 显示正常
- ✅ 下载链接可用
- ✅ 分类器（classifiers）正确

#### 测试安装
```bash
# 在新环境中测试
pip install labelcraft==1.8.11

# 验证安装
labelcraft --help

# 或者
python -c "import libs; print(libs.__version__)"
```

#### 检查 GitHub Releases
访问：`https://github.com/syd168/LabelCraft/releases/tag/v1.8.11`

确认：
- ✅ 标签已创建
- ✅ 提交记录正确
- ✅ Release notes 清晰

## 🔑 配置 PyPI API Token（可选但推荐）

为了让上传更安全，建议使用 API token 而非用户名密码：

### 1. 获取 PyPI API Token

1. 访问 https://pypi.org/manage/account/token/
2. 点击 "Add API token"
3. 填写：
   - **Token name**: LabelCraft Release Token
   - **Scope**: Entire account (account) 或特定项目
4. 点击 "Create token"
5. **立即复制 token**（只显示一次！）
   - 格式：`pypi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### 2. 配置 Twine 使用 Token

#### 方法一：命令行参数（临时）
```bash
twine upload --username __token__ --password pypi-xxxxxxxxxxxx dist/*
```

#### 方法二：配置文件（推荐）

创建 `~/.pypirc` 文件：
```ini
[distutils]
index-servers =
    pypi
    testpypi

[pypi]
repository = https://upload.pypi.org/legacy/
username = __token__
password = pypi-你的token

[testpypi]
repository = https://test.pypi.org/legacy/
username = __token__
password = pypi-你的测试token
```

设置权限：
```bash
chmod 600 ~/.pypirc
```

然后直接上传：
```bash
twine upload dist/*
```

### 3. 添加到 GitHub Secrets（用于自动发布）

如果想让 GitHub Actions 自动发布到 PyPI：

```
GitHub仓库 → Settings → Secrets and variables → Actions
→ New repository secret

Name: PYPI_API_TOKEN
Value: pypi-你的token
```

### 🔄 回滚错误发布

如果发布后发现严重问题：

```bash
# 1. 从 PyPI 删除错误的版本（需要在 PyPI 网站操作）
# 访问：https://pypi.org/manage/project/LabelCraft/releases/

# 2. 删除 Git 标签
git tag -d v1.8.11

git tag -a v1.8.11 -m "Version 1.8.11 - Fixed ..."

twine upload dist/labelcraft-1.8.11*
```

**注意**：PyPI 不允许上传相同版本号的包，必须删除后重新上传或使用新版本号。

### 🎯 语义化版本规范

遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)：

- **主版本号 (MAJOR)**：不兼容的 API 修改
  - 例如：`v1.x.x` → `v2.0.0`
  - 场景：架构重构、API 重大变更

- **次版本号 (MINOR)**：向下兼容的功能性新增
  - 例如：`v1.8.x` → `v1.9.0`
  - 场景：新功能、新特性

- **修订版本号 (PATCH)**：向下兼容的问题修正
  - 例如：`v1.8.10` → `v1.8.11`
  - 场景：Bug 修复、UI 优化、性能改进

**示例**：
- `v1.8.11`：修复深色模式配色问题（PATCH）
- `v1.9.0`：添加新的标注格式支持（MINOR）
- `v2.0.0`：完全重构 UI 框架（MAJOR）

### 🚀 自动化脚本示例

创建 `release.sh` 简化发布流程：

```bash
#!/bin/bash
set -e

VERSION=$1
if [ -z "$VERSION" ]; then
    echo "Usage: ./release.sh <version>"
    echo "Example: ./release.sh 1.8.11"
    exit 1
fi

echo "🚀 Releasing version $VERSION..."

# 1. 更新版本号
echo "📝 Updating version..."
sed -i "s/__version_info__ = .*/__version_info__ = ('${VERSION//./', '/}')/" libs/__init__.py

# 2. 提交
echo "💾 Committing changes..."
git add -A
git commit -m "Release v$VERSION"

# 3. 打标签
echo "🏷️  Creating tag..."
git tag -a v$VERSION -m "Version $VERSION"

# 4. 推送
echo "📤 Pushing to GitHub..."
git push origin main
git push origin v$VERSION

# 5. 构建
echo "🔨 Building packages..."
rm -rf dist/ build/ *.egg-info
python setup.py sdist bdist_wheel --universal

# 6. 上传
echo "📦 Uploading to PyPI..."
twine upload dist/labelcraft-${VERSION}*

echo "✅ Release $VERSION completed!"
echo "🌐 PyPI: https://pypi.org/project/LabelCraft/$VERSION/"
echo "🐙 GitHub: https://github.com/syd168/LabelCraft/releases/tag/v$VERSION"
```

使用方法：
```bash
chmod +x release.sh
./release.sh 1.8.11
```
